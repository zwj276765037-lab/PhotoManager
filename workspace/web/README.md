# PhotoManager 本地网站

这是首发验证入口：在浏览器上传一个 GIF 或视频，本机调用现有 FFmpeg 渲染器生成动态杂志封面，并直接预览、保存 MP4/GIF/JPG。

## 打开网站

进入本目录后执行：

```bash
./start.sh
```

第一次启动会在本目录创建 `.venv/` 并安装固定版本的 `imageio-ffmpeg`。启动后会同时显示本机地址和手机访问地址，例如：

```text
本机访问：http://127.0.0.1:8000/
手机访问：http://192.168.x.x:8000/
```

电脑浏览器使用本机地址。iPhone 与电脑连接同一可信 Wi‑Fi 后，在 Safari 输入终端显示的“手机访问”地址。若无法打开，请确认电脑防火墙允许该端口的局域网连接。

如 8000 端口已被使用，可以指定其他端口：

```bash
PHOTOMANAGER_PORT=8010 ./start.sh
```

按 `Ctrl+C` 停止网站。当前原型没有账号和访问密码，只应在可信局域网临时开启，不能映射到公网。

## iPhone Live Photo 使用方法

Safari 网页没有 PhotoKit 权限，无法可靠取得 Live Photo 的“静态原图＋配对 MOV”。为了确保上传后仍然会动，当前稳定流程是：

1. 在 iPhone“照片”App 打开一张 Live Photo。
2. 点右上角“…”菜单。
3. 选择“存储为视频”。
4. 回到本地网站，选择刚生成的视频并开始处理。

网站允许从照片选择器尝试选择 Live Photo；如果 Safari 只返回 HEIC/JPG 静态照片，页面会立即阻止上传并显示上述提示，不会把静态首帧误当作动态素材。真正读取成对原始资源仍需后续 iOS App 的 PhotoKit 方案。

## 当前功能

- 上传 GIF、MP4、MOV、M4V 或 WebM，单文件最大 100 MB。
- 选择先锋动态封面、斜切破版、三时态切片，或同时生成三版。
- 选择 MP4、GIF 或两者；始终生成 JPG 静态封面。
- MP4 可选择高清优先或节省空间。
- 后台串行渲染并显示任务阶段与进度，浏览器可继续查看最近任务。
- 支持 HTTP Range，生成的 MP4 可以在浏览器中播放和拖动。
- 自带示例视频，无需上传文件即可验证完整流程。

## 本地数据

上传素材、任务信息、渲染日志和输出文件仅保存在：

```text
workspace/web/runtime/jobs/<job-id>/
```

该目录和 `.venv/` 已被 Git 忽略，不会推送到 GitHub。当前是单机原型，没有账号、云端上传和多人隔离；服务为手机访问而监听局域网地址，但不要做路由器端口映射或暴露到公网。

## 清晰度说明

高清输出直接从输入素材经过无损版式母版导出，不使用网页预览文件或 GIF 回转。低分辨率、低码率和运动模糊仍受原素材上限约束，放大尺寸不能恢复未记录的真实细节。

## 后续边界

- 本地浏览器可以直接选择 GIF 和普通视频。
- 浏览器不能可靠读取 iOS Live Photo 的 PhotoKit 成对资源；原生 Live Photo 读取保留在后续 iOS App 预案中。
- 当前版式标题是固定样片文案，下一阶段再增加标题、日期、颜色和焦点编辑。
